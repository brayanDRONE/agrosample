# Tipos de despacho

En el DOM se observaron los textos: `DIRECTO`, `DISTANCIA`, `INMEDIATO`, `PENDIENTE`.

En esta sesión el request `SolicitudAgendar` envió `tipoDespacho=3` y `tipoAgendamiento=2`. El valor corresponde al flujo observado, pero no debe generalizarse a todos los textos sin una sesión específica que relacione cada opción con su value.
